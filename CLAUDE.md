# Nicolle Central

Central estratégica e de marketing do Nicolle Nogueira Studio. Next.js 14 (App Router) + Supabase + Tailwind, hospedado na Vercel.

@docs/guia.md

## Regras
- Seguir o guia fase por fase; só avançar quando a fase anterior estiver salvando dados de verdade.
- Antes de subir qualquer mudança: `npm run build` sem erro.
- Textos da interface em português.
